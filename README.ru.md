# 🎙️ SuperDictate Next

**Быстрая, приватная, локальная диктовка для macOS — включая Intel-Mac'и,
которые другие проекты оставили за бортом.** Зажмите горячую клавишу,
говорите — и текст печатается в активном поле. Без облака, без аккаунта,
аудио не покидает ваш Mac.

**[Read this in English](README.md)**

## 🌱 Зачем существует этот проект

SuperDictate Next — самостоятельное продолжение проекта
[SuperDictate](https://github.com/shlgd/SuperDictate) (который, в свою
очередь, основан на [Parakey](https://github.com/rcourtman/parakey) Richard
Courtman), форкнутого в июле 2026. Это **не** зеркало: 170+ коммитов
оригинальной работы, свой речевой движок, свой канал релизов, свой
механизм обновлений.

В апстриме не хватало трёх вещей — из-за них и появился этот проект:

1. **Intel-Mac'и.** Разработка и CI апстрима нацелены только на Apple
   Silicon. Множество ещё вполне боевых Intel-машин (этот проект собирается
   и тестируется на Xeon E5-2678 v3 с AMD Radeon RX 6600) оставались там
   непроверенной территорией. Здесь они — первоклассная цель.
2. **Другой речевой движок.** Апстрим остался на whisper.cpp. SuperDictate
   Next распознаёт речь моделью NVIDIA Parakeet (TDT 0.6B, мультиязычная)
   через ONNX Runtime, только на CPU: по точности и скорости она обошла и
   whisper.cpp, и прежнюю GGUF-сборку parakeet.cpp, включая их GPU-режимы.
   Видеокарта (Vulkan через MoltenVK) используется только локальной
   LLM-моделью коррекции и рерайта.
3. **Пространство для итераций по эргономике диктовки** в ежедневном
   русско-английском сценарии: управление словами-паразитами,
   автоостановка по тишине, полноценное окно настроек, нормализация
   русских чисел, сегментация длинных диктовок.

## 🔀 Чем отличается от апстрим-SuperDictate

| Область | Апстрим (на момент форка) | SuperDictate Next |
|---|---|---|
| Движок распознавания | whisper.cpp, large-v3-turbo | Parakeet Ultra 0.6B (ONNX int8) на ONNX Runtime, только CPU — whisper удалён полностью |
| GPU-ускорение | нет на этом пути | только для локальной LLM коррекции и рерайта (Vulkan, ggml + MoltenVK) |
| Intel-Mac'и | не тестировались | первоклассная цель, проверено на реальном железе |
| Слова-паразиты | один общий тумблер | чеклист по словам: 27 отобранных RU/EN-пресетов в 4 колонки + свои слова и фразы |
| Автоостановка | — | завершает диктовку после 1–10 с тишины (опционально) |
| Окно настроек | частичное | добавлены Launch at Login, заглушение звука при записи, адаптивный цвет **Контрастный**, размер капсулы, режимы индикатора (полоски уровня / таймер-контур) |
| Русские числа | словами | опциональная ITN: продиктованные числа цифрами (25, а не двадцать пять) |
| Длинные диктовки | один проход | сегментация по паузам с дедупликацией швов перекрытий |
| Детекция пауз | — | Silero VAD (локальный ggml-порт, скачивается автоматически) для более умных швов |
| Обучение словаря | — | автоматическое: поправьте слово сразу после диктовки — и оно запомнится, с тостом-отменой и менеджером на SQLite |
| Исправления | — | менеджер словаря (Настройки → Текст): добавление/правка/удаление, JSON-импорт/экспорт, синхронизация между Mac'ами через папку |

## 🚀 Установить за минуту

**Нужен Mac с macOS 14+ — Apple Silicon или Intel.**

1. Откройте приложение **Terminal**.
2. Вставьте эту команду и нажмите Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/shohart/SuperDictate-Next/main/install.sh | /bin/bash
```

3. В открывшемся SuperDictate нажмите `Разрешить` для **Микрофона**,
   **Универсального доступа** и **Мониторинга ввода**.
4. Дождитесь статуса `Работает`, нажмите **правый Command** и говорите.
   Нажмите **правый Command** ещё раз, чтобы вставить текст.

При первом запуске один раз загрузится локальная модель распознавания
(Parakeet Ultra 0.6B, ONNX int8). На диске она занимает около 630 МБ; для
установки лучше иметь не менее 1,5 ГБ свободного места. После
загрузки интернет для диктовки не нужен.

## Обновиться

**Если в SuperDictate уже есть кнопка `Обновить`:** откройте приложение из
папки Applications и нажмите эту кнопку. Приложение само скачает и проверит
новую версию, заменит старую и запустится заново.

**Если SuperDictate был установлен до появления кнопки обновления:** ничего не
удаляйте. Откройте Terminal и ещё раз выполните ту же команду:

```bash
curl -fsSL https://raw.githubusercontent.com/shohart/SuperDictate-Next/main/install.sh | /bin/bash
```

Команда заменяет только `/Applications/SuperDictate.app`. История, настройки и
уже загруженная модель остаются на месте. После этого следующие обновления
можно устанавливать прямо из приложения.

Последнюю опубликованную версию всегда можно увидеть на странице
[GitHub Releases](https://github.com/shohart/SuperDictate-Next/releases/latest).

## ⌨️ Горячие клавиши

- **Правый Command** — начать диктовку; повторное нажатие завершает запись.
- В настройках можно выбрать, что делает повторное нажатие: просто вставляет
  текст или вставляет текст и затем нажимает Enter.
- **Правый Option + правый Command** (по умолчанию; полностью
  перезаписываемый) — альтернативно завершить активную запись. Он выполняет
  противоположное действие: если основной хоткей нажимает Enter, этот
  завершит без Enter, и наоборот. Подходит любое сочетание, включая аккорды
  только из модификаторов вроде `Control + Command` — записывается
  удержанием аккорда и отпусканием любой из клавиш. Альтернативный хоткей
  можно выключить.
- **Правый Shift + правый Command** — открыть или закрыть быструю историю.
- Все три сочетания можно изменить независимо. Поддерживаются одиночные клавиши,
  функциональные клавиши, обычные сочетания и сочетания только из
  модификаторов, например `Option + Command`.
- Левая и правая основные клавиши различаются: сочетание с правым Command не
  сработает от левого Command.
- Пока открыто окно записи нового сочетания, глобальная диктовка временно
  приостанавливается. Нажатые клавиши только записывают новый хоткей и ничего
  не запускают.
- Откройте `SuperDictate` из Applications, чтобы проверить службу,
  разрешения и обновления. Настройки открываются кнопкой-шестерёнкой.

## 🖥️ Панель управления и настройки

Основная панель компактна: в ней видны состояние фоновой службы, недостающие
разрешения и доступное обновление. Кнопки управления службой находятся справа
от её статуса; при наведении macOS показывает пояснение к каждой кнопке.

Шестерёнка открывает окно настроек из пяти компактных вкладок:

- **Диктовка** — три сочетания и поведение завершения (вставить текст или
  вставить и нажать Enter).
- **Текст** — слова-паразиты, русский формат чисел, обучение словаря.
- **Аудио** — выбор микрофона, автоостановка по тишине, заглушение звука при
  записи.
- **Внешний вид** — размер капсулы, цвета записи/распознавания, режим
  индикатора, фон.
- **Система** — запуск при входе, сведения о приватности.

Переключатель `RU / EN` мгновенно меняет язык обеих панелей. Изменения сначала
остаются черновиком; кнопка `Сохранить и перезапустить` применяет их вместе и
перезапускает только фоновую службу. История и модель при этом не удаляются.

Панель можно полностью закрыть. Отдельная фоновая служба продолжит работать и
автоматически запустится после следующего входа в macOS.

## 🧹 Удаление слов-паразитов

Настройки → `Удалять слова-паразиты` открывают чеклист в четыре колонки:

- **27 отобранных пресетов** — слова-хезитации (`um`, `uh`, `ah`, `эм`, `м`,
  `аа`…, включены по умолчанию) и разговорные паразиты (`как бы`, `типа`,
  `короче`, `это самое`, `знаешь`, `you know`, `basically`…, выключены, пока
  вы их не отметите, — они могут быть настоящими словами).
- **Свои слова и фразы**: введите, нажмите Enter — слово попадает в тот же
  список уже отмеченным. Снятая галка оставляет слово в списке, но не
  применяет его; кнопка `×` удаляет.

## 📖 Обучение словаря

Если сразу после вставки диктовки вы руками поправите короткое слово или
фразу (классика: английское слово, продиктованное кириллицей на слух),
приложение заметит правку и запомнит её как текстовое исправление — при
следующей диктовке то же слово заменится автоматически.

- Учитываются только короткие правки (замена до трёх слов). Чистые удаления,
  недописанные обрезки и правки только регистра игнорируются.
- Рядом с полем появляется компактный тост с тем, что запомнено. Нажмите
  **Escape** или кликните по нему, чтобы сразу отменить.
- Можно править дальше: несколько исправлений в одной диктовке запоминаются
  каждое отдельно.
- Автообучение отключается в Настройки → Текст.
- Исправления хранятся в локальной базе SQLite
  (`~/Library/Application Support/SuperDictate/corrections.sqlite`), с полным
  менеджером — добавление, правка, удаление, JSON-импорт/экспорт — и
  опциональной синхронизацией через папку между вашими Mac'ами.

## ⏸️ Автоостановка по тишине

Опционально: диктовка завершается сама после выбранной непрерывной тишины
(1–10 секунд, по умолчанию 5). Тишина отсчитывается от последнего voiced-сэмпла —
ровно так, как вы это ощущаете.

## 🔐 Зачем нужны разрешения

macOS не разрешает приложению выдать их самому:

- **Microphone** — записывать голос во время активной диктовки.
- **Accessibility** — находить активное поле и вставлять готовый текст.
- **Input Monitoring** — видеть глобальную горячую клавишу.

Если после выдачи разрешений статус не стал `Ready`, откройте SuperDictate и
нажмите `Restart` у фоновой службы. Если приложение не появилось в системном
списке, нажмите `Try Again` у соответствующего разрешения.

## 📦 Что делает установщик

Установщик:

1. Загружает `SuperDictate.zip` из
   [GitHub Releases](https://github.com/shohart/SuperDictate-Next/releases).
2. Проверяет закреплённую SHA-256, версию, bundle ID, архитектуру (Apple
   Silicon или Intel), подпись и microphone-entitlements.
3. Безопасно заменяет `/Applications/SuperDictate.app` и открывает панель.

Xcode и Command Line Tools для обычной установки не нужны. История, настройки и
уже загруженная модель при обновлении сохраняются.

## 🛠️ Сборка из исходников

### Самый простой способ

Команда скачает открытый исходный код, соберёт его локально и установит
результат в `/Applications`:

```bash
curl -fsSL https://raw.githubusercontent.com/shohart/SuperDictate-Next/main/install.sh | SUPERDICTATE_BUILD_FROM_SOURCE=1 /bin/bash
```

Понадобятся бесплатные Apple Command Line Tools. Если их нет, установщик
откроет стандартный диалог установки; после его завершения запустите команду
ещё раз. Первая чистая сборка обычно занимает несколько минут.

По умолчанию сборка из исходников скачивает точный коммит исходного кода
релиза и проверяет его через GitHub. Для разработки можно передать свои
`SUPERDICTATE_REF` и `SUPERDICTATE_SOURCE_COMMIT`; без совпадения коммита
установщик не запустит скачанный `scripts/build-app.sh`.

### Ручная сборка для разработки

```bash
xcode-select --install
git clone https://github.com/shohart/SuperDictate-Next.git
cd SuperDictate-Next
swift run -c debug --package-path swift Parakey --self-test all
./scripts/build-app.sh ./dist/SuperDictate.app
open ./dist/SuperDictate.app
```

По умолчанию локальная сборка подписывается ad-hoc. Чтобы использовать свой
сертификат, передайте его имя:

```bash
SIGN_IDENTITY="Apple Development: Your Name (TEAMID)" ./scripts/build-app.sh ./dist/SuperDictate.app
```

Не перемещайте и не удаляйте `dist/SuperDictate.app`, пока фоновая служба
запущена из этой сборки. Для обычного использования предпочтительнее команда
с `SUPERDICTATE_BUILD_FROM_SOURCE=1`, которая ставит приложение в
`/Applications`.

## 🗣️ Распознавание речи: Parakeet на ONNX Runtime, только CPU

SuperDictate Next распознаёт речь моделью Parakeet Ultra 0.6B (дообученная
NVIDIA Parakeet TDT 0.6B v3, ONNX int8) в ONNX Runtime внутри
вспомогательного процесса `SuperDictateOnnxHost`. Распознавание идёт
**только на CPU**, GPU-режима для него нет. Видеокарта (Vulkan) отдана
локальной LLM, которая исправляет и переписывает текст, — см. переключатель
`LLM на GPU (Vulkan)`.

Почему только CPU: на эталонном Intel Mac (Xeon E5-2696 v3, AMD Radeon
Vega), через настоящий путь диктовки приложения (сегментация по паузам,
окна с перекрытием, дедупликация швов), 8 клипов от 1,7 до 52 с, 8 потоков,
без LLM-коррекции:

| Движок | Средний WER | Средний F1 пунктуации | Средний RTF | Загрузка, с |
|---|---:|---:|---:|---:|
| **ONNX, CPU** | **0,079** | **0,965** | **0,119** | 3,7 |
| parakeet.cpp GGUF q8_0, CPU | 0,084 | 0,909 | 0,182 | 5,5 |
| parakeet.cpp GGUF q8_0, Vulkan | 0,084 | 0,909 | 0,133 | 6,0 |
| whisper.cpp large-v3-turbo q8_0, Vulkan | — | — | 0,63–6,4 | 17 |

whisper.cpp тратит около 11 с на каждый вызов независимо от длины клипа
(дополняет вход до 30-секундного окна), так что 2-секундная команда
распознавалась 11 с; на этом прогон остановлен, точность не оценивалась.
Движки GGUF и Whisper удалены 2026-10-17; подробности — в
`docs/specs/cross-platform-onnx-asr-spec.md`, §12.

## 🎚️ Детекция пауз (Silero VAD)

Длинные диктовки разрезаются на сегменты по паузам (лёгкая эвристика по
мел-энергии), распознаются окнами с перекрытием и склеиваются обратно. Швы
между окнами ставит [Silero VAD](https://github.com/snakers4/silero-vad) —
ggml-сборка `ggml-silero-v6.2.0.bin` (885 КБ, MIT), которую SuperDictate сам
скачивает в фоне в `~/Library/Application Support/SuperDictate/Models/` после
загрузки модели распознавания (закреплённая ревизия, проверка размера и
SHA-256). VAD работает локально на CPU; пока файла нет (или нет сети), швы
ставятся по эвристике мел-энергии, и всё продолжает работать.

## ✅ Проверки перед pull request

```bash
bash -n install.sh uninstall.sh scripts/*.sh
plutil -lint swift/Info.plist entitlements.plist
swift run -c debug --package-path swift Parakey --self-test all
./scripts/build-app.sh ./dist/SuperDictate.app
codesign --verify --deep --strict ./dist/SuperDictate.app
otool -L ./dist/SuperDictate.app/Contents/MacOS/SuperDictate
file ./dist/SuperDictate.app/Contents/MacOS/SuperDictate
lipo -info ./dist/SuperDictate.app/Contents/MacOS/SuperDictate
```

`otool -L` не должен содержать `/usr/local`, `/opt/homebrew`, `Cellar`,
`MoltenVK.dylib` или `libvulkan`: в исполняемом файле приложения есть только
CPU-ядро ggml для Silero VAD и никакого GPU-кода, а LLM-хелпер
(`Contents/Helpers/SuperDictateLLMHost`) линкует MoltenVK статически —
единственные рантайм-зависимости это системные фреймворки Apple.

GitHub Actions повторяет самотесты, собирает bundle, прогоняет установщик на
чистом macOS runner и проверяет удаление.

### Бенчмарк распознавания речи

`scripts/benchmark-asr.sh` — постоянный, переисполняемый скрипт:
синтезирует фиксированный корпус через `say`/`afconvert` (RU/EN/смешанный,
короткие команды, числа, технические термины, ~30 с и ~120 с фрагменты),
прогоняет каждый клип через реальную точку входа
`--benchmark-transcribe onnx cpu <потоки>` (проверяется до создания
`NSApplication`, поэтому никогда не проваливается в обычный запуск) и
собственный сегментированный путь диктовки, и пишет отчёт с WER, CER, F1
пунктуации, холодной загрузкой, разогревом, первой транскрипцией,
медианной/p95 тёплой задержкой, RTF и пиковой RSS. Нужен собранный бандл
(`scripts/build-test-app.sh`): ONNX-хелпер лежит в `Contents/Helpers`.

## ⚠️ Ограничения

- Поддерживаются Apple Silicon и Intel Mac на macOS 14 или новее. Windows и
  Linux пока не поддерживаются. Поддержка Intel проверена ручным
  тестированием только на одной конкретной машине (Xeon E5-2678 v3 + AMD
  Radeon RX 6600, macOS 15.7.7), а не через CI: размещённые GitHub раннеры
  macOS доступны только на Apple Silicon, поэтому автоматической проверки
  этого пути пока нет.
- Публикуемый `SuperDictate.zip` собран для Intel (x86_64). На Apple
  Silicon устанавливайте командой сборки из исходников — установщик проверяет
  архитектуру и сообщит об этом явно.
- Публичная сборка подписана ad-hoc и не нотарифицирована Apple. Установка
  через команду выше проверена, но ZIP, скачанный вручную через браузер, может
  вызвать предупреждение Gatekeeper.
- Из-за отсутствия стабильной Developer ID подписи macOS иногда повторно
  запрашивает разрешения после обновления. Нотаризация требует платного
  аккаунта Apple Developer.
- Первый запуск требует интернет для загрузки модели. Панель проверяет
  обновления при открытии; фоновая автопроверка, если включена, обращается к
  публичному GitHub API раз в шесть часов.
- Одна запись автоматически завершается через 20 минут. При аварийном
  завершении незаконченная запись сохраняется для восстановления истории.
- Защищённые поля паролей и приложения, которые скрывают Accessibility-данные,
  могут не отдавать координаты каретки. Это влияет на положение анимации, но
  не всегда мешает вставке текста.
- Ориентир по ресурсам на текущей сборке: около 630 МБ на диске для модели
  распознавания (ONNX int8, CPU). Пиковая резидентная память ONNX-хелпера —
  около 2,2 ГБ (с учётом отображённых страниц модели); сам процесс
  приложения держится в пределах 40–60 МБ.

## 🔒 Данные и приватность

- История и настройки: `~/Library/Application Support/SuperDictate`.
- Модель распознавания: `~/Library/Application Support/SuperDictate/onnx`.
  (Файлы GGUF Parakeet и whisper.cpp от прежних версий — в
  `~/Library/Application Support/SuperDictate/Models` и
  `~/Library/Application Support/Whisper/Models` — больше не используются,
  их можно удалить.)
- LaunchAgent: `~/Library/LaunchAgents/com.local.superdictate.agent.plist`.
- Логи: `~/Library/Logs/SuperDictate*`.
- Аналитики, аккаунтов и телеметрии нет.

Подробнее: [PRIVACY.md](PRIVACY.md).

## 🗑️ Удаление

```bash
curl -fsSL https://raw.githubusercontent.com/shohart/SuperDictate-Next/main/uninstall.sh | bash
```

Приложение и фоновая служба удаляются. История, настройки и модель сохраняются,
чтобы случайно не потерять данные и не загружать модель повторно.
